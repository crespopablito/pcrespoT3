# pcrespoT3

Aplicación móvil en .NET MAUI (.NET 10) para registrar contactos y calcular el aporte personal al IESS (9,45 %).

## Vistas
- `Views/vHome`: formulario de ingreso (tipo de identificación, identificación, nombres, apellidos, fecha de nacimiento, correo y salario) con validaciones. Usa estilos implícitos.
- `Views/vResumen`: muestra los datos en Labels, el aporte al IESS y exporta a un archivo de texto. Usa estilos explícitos.

## Ejecutar
Abrir `pcrespoT3.slnx` en Visual Studio 2026 con la carga de trabajo de .NET MAUI y ejecutar en Windows o en un emulador Android.
